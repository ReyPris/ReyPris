### ▸ // ENGINEERING PRINCIPLES

- **Explicit over magic:** Keep code readable, modular, and typed throughout.
- **Relational integrity:** Foreign keys, migrations, and transactional isolation at the database level.
- **Isolated deployment:** Zero local machine dependencies; everything builds and runs cleanly via Docker Compose.
- **Zero secrets in code:** Strict environment overlay segregation from dev to production.
