| **Telegram TMA и Боты** | Нативные Telegram WebApps (Mini Apps), синхронизация корзины, авторизация по HMAC initData, боты для ритейла и склада, TON Connect. *(Aiogram 3, TMA SDK)* |
| **AI-Агенты и Парсинг** | Автономные парсеры с обходом защит, интеграция LLM-агентов для обработки каталогов, RAG-поиск по документам и базам знаний. *(Playwright, LangChain, AsyncIO)* |
